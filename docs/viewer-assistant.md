# 시청자 시연 도우미

시청자 헤더의 Gemini 모양 아이콘을 누르면 오른쪽에서 ‘어떤 것을 도와드릴까요?’ 패널이 열립니다. ‘시연을 위해 목업 채팅을 만들어줘. 1초에 1개씩 30개만’ 버튼으로 1초 뒤부터 초당 1개씩 30개를 미리 보여줍니다.

현재 Gemini API 연결은 없으며 고정 예시 문장을 사용하는 목업입니다. 패널에 이를 명시했고 실제 방송 채팅이나 검토 대기열에 섞지 않습니다. API 콘솔에서도 동일한 로컬 미리보기를 제공합니다. Backend·Agent·인증·ERD 변경과 Gemini 비밀키는 없습니다.

생성 중 버튼은 비활성화되고 건수가 표시됩니다. 중지 버튼, 패널 닫기, 계정/방송 범위 변경, 화면 해제 시 타이머를 중단합니다. 완료 후 재실행하면 목록을 초기화합니다. Esc·배경 클릭으로 닫기, 버튼 초점 복귀, 패널 안 키보드 순환 및 움직임 줄이기를 지원합니다.

## 검증

프로덕션 빌드 통과. Docker frontend만 재빌드하여 localhost:3000 반영. 신규 목업/API 브라우저 테스트 2/2 통과: 첫 999ms는 0개, 1000ms는 1개, 30초에 정확히 30개와 이후 추가 없음, 중복 실행 방지, 중지·닫기 취소, Esc 초점 복귀, 360px 가로 넘침 없음, 실제 messages POST 0회. 실제 API 콘솔에서도 3초간 3개 생성과 390px 패널 표시를 직접 확인했습니다. 이번 변경 후 전체 회귀 테스트는 실행하지 않았습니다.
