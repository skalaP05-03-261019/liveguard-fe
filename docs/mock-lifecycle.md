# 목업 방송 생명주기와 조사 지연 (#30)

목업과 실제 API 콘솔은 같은 `StudioScreen`·`ViewerScreen`을 사용한다. 이번 변경은 목업 데이터 계층에만 방송 시작·종료와 조사 지연을 더한다. 실제 API 요청 경로는 바꾸지 않는다.

## 시연 흐름

1. 스트리머 목업에서 방송 관리 메뉴의 **방송 종료**를 누른다. 시청자 화면은 “방송이 종료되었습니다”를 보이고 채팅을 보낼 수 없다.
2. **라이브 스트리밍 시작**을 누르면 새 `liveId`가 만들어진다. 이전 방송의 메시지·사건·검토·제재는 새 방송으로 넘어오지 않는다.
3. 빠른 시연 또는 시청자 직접 입력으로 공격 표현·개인정보 후보를 보내면 `HELD`와 **AI 조사 중** 상태를 약 3초간 표시한다. 이후 목업 Agent의 고정 판정이 반영된다. 초기 fixture는 화면을 열자마자 준비된 상태로 유지한다.
4. 조사 도중 방송을 종료하면 예정된 목업 판정은 취소된다. 새 방송을 시작해도 이전 조사가 결과를 쓰지 않는다.

개인정보 경로는 정책 v3.2 A-28을 따른다. 목업 Agent가 `PII_EXPOSURE` 단독 위반으로 판정한 경우 백엔드 역할의 목업 로직이 운영자 결정 없이 확정·숨김 처리한다. 다른 운영자 판단 유형이 섞이거나 근거가 부족하면 문맥 검토로 넘긴다. 이는 실제 모델의 품질 측정이 아니라 고정 규칙으로 만든 시연 결과다.
